The Language for Systems & Cloud

Roze is a fast, statically typed language featuring deterministic atomic reference counting, dual native Cranelift & JVM backends, safe concurrency, and full self-hosting independence.

$ curl -fsSL https://roze-lang.org/install.sh | bash

⚡ Dual-Backend Architecture

Compile to ultra-fast standalone native ELF/Mach-O/PE binaries via Cranelift, or target the JVM for seamless enterprise Java interoperability.

🛡️ Deterministic ARC Memory

Thread-safe automatic reference counting without garbage collection pauses. Deterministic destructors reclaim memory the moment it goes out of scope.

🌐 Pure Self-Hosting

Written in Roze, compiled by Roze. Proven via 3-stage bootstrap fixpoint verification with byte-for-byte compiler idempotence.

🎮 Multi-Domain Power

Build 60 FPS games via Raylib FFI, enterprise REST services with RozeBoot, local AI inference with GGML/LLaMA, or bare-metal multiboot2 OS kernels.

// Algebraic Data Types & Exhaustive Pattern Matching
enum Result<T, E> {
    Ok(val: T),
    Err(msg: E)
}

func divide(a: int, b: int) -> Result<int, string> {
    if b == 0 {
        return Result::Err("division by zero");
    }
    return Result::Ok(a / b);
}

func main() {
    let res = divide(100, 5);
    match res {
        Result::Ok(v) => println("Result: " + v),
        Result::Err(e) => println("Error: " + e)
    }
}
