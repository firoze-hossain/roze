# Change Log

## [1.0.0] - 2026-10-27

### Added
- Official v1.0.0 production release.
- Added syntax highlighting for `enum`, `trait`, `impl`, `unsafe`, and `extern`.
- Added support for algebraic data types, pattern matching (`match`), and `Result`/`Option` `?` operator.
- Updated LSP client diagnostics integration with `roze-lsp`.
- Added comprehensive code snippets for modern language constructs.
- Added official logo icon.
